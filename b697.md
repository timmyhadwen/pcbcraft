## What
The guide folder layout, the page template, the `{{ui:key}}` and `shot:` syntax, one example page, and the first half of `cargo xtask guide-check`, run in the existing `docs-check` CI job.

## Why
A guide step must name a control exactly as the app labels it, so a rename breaks the build instead of the manual.

## How
1. Create docs/guide/en/ with section folders `start`, `howto`, `reference`, `concepts` and docs/guide/en/index.toml for titles and order.
2. Front matter: `title`, `area`, `kind` (tutorial|howto|reference|concept), `story`, `shots`, `since`. Body: one goal sentence, 'Before you start', numbered steps, 'What you should see', 'If it did not work', related pages. Sentences at most 20 words; follow docs/doc-standard.md and docs/tooltips.md.
3. Directive `{{ui:board.tool_strip.route}}` renders the label from crates/text/strings/en.txt in bold, in the page language. `![](shot:board-route-track)` embeds a catalog shot.
4. New xtask/src/guide_check.rs, registered in xtask/src/main.rs and added to the `docs-check` job (.github/workflows/ci.yml, `cargo xtask docs check` today). Checks: every `{{ui:key}}` exists in en.txt; a bold step label not produced by a directive is an error; every `shot:` id exists in docs/shots/catalog.toml (skipped with a note until that file exists); every page has at least one shot; the repo text rules (no em-dashes, no other tool names) plus the sentence length limit; internal links and anchors resolve, links to docs/*.md exist.
5. Reverse coverage ratchet in a `[guide_coverage]` table of xtask/doc-ratchet.toml: the count of `menu.*`, `board.tool_strip.*` and `docks.workbench_tabs.*` keys no page mentions. CI fails if it rises and says to lower it if it falls.
6. Write one example page: `docs/guide/en/start/install-and-open.md`.

## Acceptance
1. `cargo xtask guide-check` passes on the example page and fails on each seeded error.
2. The check runs in `docs-check`.
3. English only; no other language folder is created.

## Tests
In xtask/src/guide_check.rs: `an_unknown_ui_key_fails`, `a_bold_label_without_a_directive_fails`, `a_missing_shot_id_fails_once_the_catalog_exists`, `a_long_sentence_fails`, `a_broken_internal_link_fails`, `the_coverage_ratchet_rejects_a_rise`.
