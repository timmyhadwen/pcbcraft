## What
Reference pages built from en.txt and the engine command table by an xtask, so they cannot drift.

## Why
Reference is the part of the guide that is long and mechanical; writing it by hand guarantees drift.

## How
1. Generate docs/guide/en/reference/*.md: menus (`menu.*`), tools (`board.tool_strip.*`), keyboard shortcuts (`shortcut.*`, 34 keys), checks (`check.*`, 37), settings, and commands from `pcbcraft_engine::commands()` (crates/engine/src/lib.rs). The `.tip` text is the description.
2. Read command data from the JSON written by `cargo xtask site-data` (#713) so there is one loader. Keys come from en.txt through the existing strings xtask code.
3. `guide-check` fails when a generated page differs from a fresh generation.

## Acceptance
1. Every `shortcut.*` and `check.*` key appears once.
2. A new engine command appears in the commands page after regeneration, and CI fails if the page is stale.

## Tests
`reference_pages_list_every_shortcut_key`, `reference_pages_list_every_check_key`, `a_stale_reference_page_fails_guide_check`.
