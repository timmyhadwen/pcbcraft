## What
Check crates/mcp against the current MCP specification (the revision 2025-11-25 and the version negotiation rules) and write the findings as docs/mcp-conformance.md. On fork main the server answers initialize (accepts 2025-11-25, 2025-06-18, 2024-11-05), tools/list and tools/call, and advertises only `tools: {listChanged: false}`. Items to check: capability negotiation and the rule to return a version the client supports; ping; notifications/initialized and cancelled; tool annotations (readOnlyHint, destructiveHint), output schemas and `structuredContent` versus text; error shape for tool failures (isError result versus JSON-RPC error); pagination of tools/list (cursor); resources (`resources/list`, `resources/read` for the design, the command list, check results); prompts (`prompts/list`) for common tasks; logging; JSON-RPC batch and id rules. Transports: stdio framing today, the loopback TCP bridge (not a spec transport), and Streamable HTTP (single endpoint, POST and optional SSE, Origin validation, session id header, authorization). File one issue per gap found.
