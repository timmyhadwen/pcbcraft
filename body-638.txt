## What
A protocol conformance test module for the MCP server that walks the spec feature table of `docs/mcp-conformance.md` (#613). Contributes the protocol part of #509.

## Why
The owner wants the in-app MCP server tested against the specification, not only tool by tool. Today one test covers negotiation and one covers framing.

## How
Base: fork/main at a0b7682. New file `crates/mcp/src/protocol_tests.rs`, declared in `lib.rs` as `#[cfg(test)] mod protocol_tests;`. Use `handle_rpc` and `serve` with `DocumentHub::new(Session::default(), None)`.

## Acceptance
Each is one test; names are the contract:
1. `initialize_answers_each_supported_version_and_falls_back_to_the_newest_for_an_unknown_one` (2025-11-25, 2025-06-18, 2024-11-05, 1999-01-01).
2. `initialize_without_client_info_is_refused_with_invalid_params`.
3. `a_notification_never_gets_a_reply`.
4. `ping_returns_an_empty_object`.
5. `an_unknown_method_gets_method_not_found`.
6. `a_request_with_the_wrong_jsonrpc_version_or_a_missing_method_gets_invalid_request`.
7. `a_json_array_request_is_rejected_because_batching_is_not_supported`.
8. `broken_json_gets_parse_error_with_a_null_id`.
9. `every_tool_name_is_one_to_128_letters_digits_underscore_hyphen_or_dot`.
10. `an_unknown_tool_name_is_a_protocol_error_but_bad_arguments_are_a_tool_error_with_is_error_true`.
11. `a_tool_result_carries_text_content_and_a_structured_copy`.
12. `a_message_over_one_mebibyte_is_refused_and_stdout_stays_json_only`.
13. `capabilities_advertise_only_tools_and_resources_and_prompts_calls_are_method_not_found`.
Tests 10 and 13 change when #614 lands; note it in the test comments. Annotation and lifecycle tests belong to the children for those features.
