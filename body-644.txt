## What
The MCP server advertises `prompts` and answers `prompts/list` and `prompts/get` with three prompts: `review_board`, `fix_unrouted_nets` and `prepare_fabrication`. Child 3 of #614.

## Why
Prompts are user-controlled templates for common tasks (revision 2025-11-25, server/prompts). They name tools and never hold secrets or paths.

## How
Base: fork/main at a0b7682. `crates/mcp/src/lib.rs`, `handle_rpc`; code in a new `crates/mcp/src/prompts.rs`.
- Capabilities gain `"prompts":{"listChanged":false}` (same line as the resources child; serialize).
- `review_board` (optional argument `focus`: one of `placement`, `power`, `signal`): messages tell the model to call `inspect_design` and `checks`, then review the chosen focus and report findings by object id without editing.
- `fix_unrouted_nets` (no arguments): call `checks`, list the unrouted nets, route them with `execute` or `batch`, then call `checks` again and report what is left.
- `prepare_fabrication` (argument `fab`, a short text): run `checks`, stop and report if errors remain, then use the output tools (`gerber.export`, `bom.write`, `placement.write`).
- `prompts/get` returns `{description, messages:[{role:"user", content:{type:"text", text}}]}`; an unknown name or an argument not in the enum is JSON-RPC -32602.
- Argument values are inserted as plain text, length-capped at 200 characters.

## Acceptance
Tests in `crates/mcp/src/prompts.rs`:
1. `prompts_list_names_three_prompts_with_their_arguments`.
2. `review_board_with_focus_power_mentions_power_and_both_tools`.
3. `an_unknown_prompt_or_a_bad_focus_gives_invalid_params`.
4. `every_tool_a_prompt_names_exists_in_the_tool_list`.
5. `a_long_argument_is_clipped`.
