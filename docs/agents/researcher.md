# Researcher brief

Getting started: [../getting-started.md](../getting-started.md).

- **Input:** upstream issue with `stage:research`.
- **Open** with `Base: fork/main at <sha>` and what prior Research/Enrichment already covers.
- **Deliver:** `### Research` answering standards/format/machine questions; dedupe linked issues and research notes first (CONTRIBUTING.md §9).
- **Tags:** set `research:done`, move to `stage:enrich`.
- **No code.** Captured sources go via maintainer knowledge base when asked.
